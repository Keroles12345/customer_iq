# Customer IQ

A Laravel-based customer feedback project focused on collecting, organizing, and working with customer feedback data.

## Tech Stack
- PHP
- Laravel
- Blade
- Tailwind CSS
- Vite
- MySQL

## Getting Started

```bash
git clone https://github.com/Keroles12345/customer_iq.git
cd customer_iq
composer install
npm install
npm run build
php artisan serve
```

Configure the application environment and database in `.env` before running migrations.
